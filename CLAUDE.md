# Планиметрика — правила для Claude

Планиметрика (planimetrika.online) — подготовка к ЕГЭ по профильной математике в стиле Duolingo:
путь из уроков, теория, задачи с проверкой, повторение, «Мои ошибки», пробники ЕГЭ, кабинет
репетитора и родителя. Владелец — Павлов Артём, репетитор по математике.

**Пиши Артёму по-русски, коротко и без жаргона.** В конце работы — что сделано, что запушено
и что ему нужно сделать руками (если нужно).

Карта модулей, потоки данных и подводные камни — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
Прочитай её, прежде чем менять незнакомую часть.

## Стек

- Сайт: Next.js 15 (App Router) + React 19 + Drizzle ORM + Postgres. Миграции — `drizzle/`,
  схема — `lib/db/schema.ts`, все запросы к базе — через `lib/queries.ts` и соседние `lib/*`.
- Контент задач — `scripts/seed.ts`.
- Мобильное приложение — Expo (React Native) в `mobile/`, ходит на сайт через `/api/m/*`.
  Пакет `ru.planimetrika.app`, проект EAS `riikinkukko/mathapp`.
- Пуш в `master` → GitHub Actions: тестовая база, `npm test`, сборка, смоук-тест страниц
  (Playwright), затем деплой на сервер (`scripts/deploy.sh`: миграции → сборка → pm2 restart,
  при падении сборки откат на прежнюю).

## Правила (нарушать нельзя)

- **Никогда не запускать `npm run seed:reset` на проде** (стирает данные). Обычный `npm run seed` можно.
- Не трогать `app/legal/*` и `components/PublicFooter.tsx`.
- Секреты (токены, пароли, ключи) не писать в чат и не коммитить — только в `.env.local` на сервере.
- Не коммитить `tsconfig.tsbuildinfo` (кэш сборки) и `.env*`.
- Не давать аккаунт `teacher@demo.ru` (админ) проверяющим Google Play и жюри.
- В Android-приложении не показывать оплату (правила Google Play): тариф оформляется только на сайте.
- Чертежи: четырёхугольник ABCD в школьной записи — A левый нижний, B левый верхний,
  C правый верхний, D правый нижний (AD снизу, BC сверху). У параллелепипеда и пирамиды AD — переднее ребро.
- Команды `eas` — только из папки `mobile`. Правки только в JS — `eas update`; новая нативная
  библиотека или смена версии в `app.json` — новая сборка с поднятым `android.versionCode`.
- Коммить небольшими осмысленными коммитами прямо в `master`. После пуша убедись, что
  GitHub Actions зелёный, иначе чини сразу.
- Изменения в **существующих** задачах на проде — миграцией с `UPDATE` (seed на проде сам не запускается).
  Если всё же нужен `npm run seed` на проде — скажи об этом Артёму явно.
- Решения, которые нельзя откатить (удаление данных, платёжные настройки, изменения на сервере), —
  сначала спросить Артёма.

## Команды

```bash
npm ci                       # зависимости
npm run dev                  # локальный сайт на :3000
npx tsc --noEmit             # проверка типов
npm run test:db              # пересоздать ТЕСТОВУЮ базу (миграции + демо-данные)
npm test                     # логические тесты (tests/unit, нужна тестовая база)
npm run build                # сборка
BASE_URL=http://localhost:3100 npm run test:e2e   # смоук-тест (нужен запущенный next start на тестовой базе)

npx drizzle-kit generate     # SQL-миграция из изменений schema.ts → drizzle/
npx drizzle-kit migrate      # применить миграции
npm run seed                 # залить/обновить демо-данные и контент

cd mobile && npx tsc --noEmit                    # типы приложения
cd mobile && npx expo export --platform web      # веб-сборка приложения (для проверки экранов)
cd mobile && eas update --channel preview        # JS-обновление на телефоны
```

**Перед каждым пушем:** `npx tsc --noEmit`, `npm test`, `npm run build`
(и `cd mobile && npx tsc --noEmit`, если трогал приложение).

## Локальное окружение

Скопируй `.env.local.example` в `.env.local`. Нужны две базы Postgres: рабочая (`DATABASE_URL`)
и тестовая (`TEST_DATABASE_URL`, имя обязано содержать «test» — защита от стирания).
Тесты сами отключают Telegram, почту, push и ЮKassa (`tests/setup.ts`).
