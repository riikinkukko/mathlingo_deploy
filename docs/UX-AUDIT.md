# Аудит UX — ноябрь 2026

Проверено: все экраны ученика (student, free, pro), репетитора и родителя на ширинах 375, 768 и 1440
(Playwright, скриншоты + автопроверки: горизонтальная прокрутка, мелкие кнопки, выход за край,
ошибки в браузере), отдельно — все всплывающие меню и выпадающие списки (открыть → помещается ли
в экран → закрывается ли тапом мимо), веб-сборка мобильного приложения (`expo export --platform web`).

Общий вывод: интерфейс аккуратный, горизонтальной прокрутки и ошибок загрузки нет ни на одной
странице. Ниже — найденные проблемы по важности.

## Исправлено

| Важность | Проблема | Где |
|---|---|---|
| Высокая | Из профиля Android-приложения можно было дойти до оплаты на сайте (риск для Google Play) | `lib/app-context.ts`, `app/auth/app/route.ts`, страницы тарифа |
| Высокая | Подсказки «Серия» / «Опыт» в шапке ученика уезжали за левый край телефона | `components/StatChip.tsx` |
| Средняя | Выпадающие списки (select) выглядели по-разному в разных браузерах, на iPhone — серые | `app/globals.css` |
| Средняя | Точки-переключатели задач в домашке 14 px в ширину — пальцем не попасть | `components/AssignmentFlow.tsx` |
| Средняя | «Цель дня» считалась по UTC, серия — по Москве: с 0 до 3 ночи цель показывала вчерашнее | `lib/queries.ts:computeDailyGoal` |
| Средняя | Подсказка серии обещала «закрываешь цель дня», а серию продлевает любая задача | шапка ученика |
| Средняя | В приложении окно выбора режима пробника не листалось и уходило под системную панель | `mobile/src/app/(tabs)/mocks.tsx` |
| Низкая | «Прогресс по навыкам: 2/1189 задач» у родителя и репетитора пугал и ничего не говорил | карточки ученика |
| Низкая | Цель «оплата прошла» в Метрике засчитывалась при каждом обновлении страницы | `components/Analytics.tsx` |
| Низкая | Поле «Целевой балл» узкое, подсказка обрезалась; то же у «Лимита времени» в задании | `components/StudentGoalForms.tsx`, `app/teacher/homework/new/page.tsx` |
| Низкая | В приложении ученику с репетитором писали «без почты энергия не восстанавливается» | профиль приложения |

## Как повторить

Скрипты аудита не входят в репозиторий; суть — Playwright с `executablePath` системного Chrome,
вход за каждого демо-пользователя и обход страниц из `tests/e2e/smoke.ts` на трёх ширинах.
